High-Resolution Polar Transformer

Turning a ring photo into an in-game 3D ring

This tool's main job is unrolling a ring photo into a strip texture you can wrap around a planet in-editor. Here's the full workflow, start to finish.

  1. Find a reference photo. Take or find a gas giant picture with rings shown at an angle (a real photo of Saturn works great, like the one above).
  2. Upload it here and drag the guides: set Inner Radius to the visible edge of the planet itself, and Outer Radius to just past the outer edge of the rings — so the ring band between them covers the full rings, but not the part of them hidden behind the planet.
  3. Hit Unroll (Equirect), wait for it to render, then download both the Current View (the unrolled ring strip) and the Inner Circle (the cropped planet disc).
  4. Back in the main editor, set the unrolled ring strip as the body's Atmosphere texture.
  5. Set the inner circle image as the Front Cloud texture, and adjust its settings so it doesn't fade — set Fade Zone Height to 0.
  6. Adjust the Atmosphere Height so it lines up with the front cloud layer — nudge it until the ring sits flush against the planet's edge with no gap or overlap.
